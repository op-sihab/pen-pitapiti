# Game Audio Assets (SFX)

This folder contains all high-fidelity sound effects used by the Pen Fight physics and match engine:

| Clean Name | Purpose | Original Hash File |
|---|---|---|
| `flick-1.mp3` / `flick-2.mp3` | Pen flick release launch sounds | `pen-flick-*.mp3` |
| `pen-collide-1..4.mp3` | High-impact plastic & body collisions between pens | `pen-hit-plastic-*.mp3` |
| `wood-impact-1..4.mp3` | Tabletop bounces and sliding impacts on wooden desks | `pen-desk-wood-*.mp3` |
| `floor-drop-1..2.mp3` | Falling off the desk edge (Ring-out knockout) | `pen-fall-floor-*.mp3` |
| `metal-ting-1..2.mp3` | Stylus & metallic pen tip reflections | `pen-ting-metal-*.mp3` |
| `pen-aim-grab.mp3` | Player touch / pointer grab and drag aim sound | `pen-grab-1.mp3` |
| `slide-friction-loop.mp3` | Desk friction drag looping track | `pen-slide-paper-loop.mp3` |
| `turn-notification.mp3` | Turn handoff chime | `turn-change.mp3` |
| `match-victory.mp3` | Victory xylophone celebration fanfare | `win-xylophone.mp3` |
| `match-defeat.mp3` | Match defeat chime | `lose-steel.mp3` |

To add or replace a sound, place your .mp3 file here.
