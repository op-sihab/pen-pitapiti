# Desk Arenas & Background Textures

This folder contains high-resolution WebP desk arena backdrops rendered in the Pixi.js WebGL game stage:

| Clean Name | Style / Theme |
|---|---|
| `clean-pine-light.webp` / `clean-pine-dark.webp` | Classic school pine wood desk |
| `old-school-light.webp` / `old-school-dark.webp` | Vintage scratched school desk |
| `vintage-mahogany.webp` | Executive deep mahogany wood |
| `classroom-blackboard.webp` | Slate blackboard with chalk lines and dust |
| `cyber-grid-arena.webp` | Glowing cybernetic Tron-style grid |
| `studio-birch.webp` | Scandinavian minimalist light birch table |

### Recommended Dimensions:
- Resolution: ~1440x960px or 1920x1080px
- Format: High-efficiency WebP (quality 85)
